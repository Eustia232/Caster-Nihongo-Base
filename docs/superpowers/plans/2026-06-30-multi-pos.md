# Multi-Part-of-Speech Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Allow a word to have multiple parts of speech (List[str] instead of str), add `自动词` and `他动词` POS types.

**Architecture:** Change `Word.pos` from `str` to `List[str]` with a Pydantic validator. Split comma-separated POS on import, use "、" for display, treat composite as classification key in export. Auto-migrate existing string POS on load.

**Tech Stack:** Python 3.12+, Pydantic, pytest, uv

## Global Constraints

- Same kana and meaning for all POS of a word
- Import POS separator: 中英文逗号 (`，` or `,`)
- Display connector: 顿号 (`、`)
- POS_ORDER: `名词, 名词サ变, 动词1, 动词5, 自动词, 他动词, 形容词, 形容动词, 副词`
- Export sort: by first POS in POS_ORDER, tie-break by full classification string
- No standalone migration script; auto-wrap on load

```python
from typing import List, Dict, Optional, Union, Any, Tuple
from datetime import datetime
from pydantic import BaseModel, Field, field_validator


ALLOWED_POS = [
    "名词", "名词サ变",
    "动词1", "动词5",
    "自动词", "他动词",
    "形容词", "形容动词", "副词",
]


class Word(BaseModel):
    id: int = Field(..., description="单词唯一标识 ID")
    kanji: str = Field(..., description="日文汉字")
    kana: str = Field(..., description="假名（含音调，如：たべる2）")
    meaning: str = Field(..., description="中文释义")
    pos: List[str] = Field(..., description="词性列表")
    category: Optional[str] = Field(
        None, description="可选：单词分类，例如 JLPT 等级或主题"
    )

    @field_validator("pos", mode="before")
    @classmethod
    def ensure_list(cls, v):
        if isinstance(v, str):
            return [v]
        return v

    @field_validator("pos")
    @classmethod
    def validate_pos_values(cls, v):
        for item in v:
            if item not in ALLOWED_POS:
                raise ValueError(
                    f"非法词性 '{item}'，允许值: {', '.join(ALLOWED_POS)}"
                )
        return v

    @property
    def pos_str(self) -> str:
        return "、".join(self.pos)
```

            data = yaml.safe_load(f) or []

def parse_line(self, line: str, word_id: int) -> Word:
    line = line.strip()
    if not line:
        raise ValueError("Empty line")

    parts = [p.strip() for p in line.split("|")]
    if len(parts) not in (4, 5):
        raise ValueError(
            f"格式错误，应为 '汉字|假名+音调|释义|词性' 或加上可选 'category': {line}"
        )

    category = None
    if len(parts) == 5:
        category = parts[4] if parts[4] != "" else None

    import re as _re
    pos_raw = parts[3]
    pos_list = [p.strip() for p in _re.split(r"[，,]", pos_raw) if p.strip()]

    return Word(
        id=word_id,
        kanji=parts[0],
        kana=parts[1],
        meaning=parts[2],
        pos=pos_list,
        category=category,
    )
